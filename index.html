Featured project: IkiAstrro

IkiAstrro, an astrology computation engine and analysis app

A research-oriented Vedic astrology (Jyotisha) engine that calculates, organises and explains the evidence in a horoscope, so an astrologer can see strengths, weaknesses, confirmations and conflicts without missing them in a large body of chart data. Built end to end under Ikijunar as product owner and builder, using AI-assisted development.

What it does
  • Generates birth charts and all 20 divisional charts (D2 to D60)
  • Selectable ayanamsa catalogue (22 systems), with Lahiri as the default
  • Houses, nakshatras, dignities, karakas, Vimshottari dasha
  • Source-attributed yoga detection and strength analysis (in progress)
  • Saved-chart management and print-ready reports
How it is built
  • .NET 10 / C# calculation engine with Swiss Ephemeris positions
  • SQL Server with hand-written SQL (Dapper), full calculation provenance
  • Blazor Server UI with hand-rolled SVG chart diagrams
  • Automated tests; results checked against an established reference tool
  • 700+ commits, tracked backlog, documented architecture and decisions

Product practice shown here: backlog ownership, release cadence, documented decisions, a clear definition of done, and honest status reporting (calculations are marked experimental until validated).
